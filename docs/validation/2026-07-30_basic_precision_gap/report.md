# 2026-07-30 基础题视觉精度与 0.2 mm 间隙验证

## 范围

本次只验证视觉感知与拼图规划，不启动串口桥，不执行机械移动，也不把规划坐标当作
实物落位精度。生产 debug 相机画面当时没有摆放拼图块，因此另用项目已有基础题手机
照片完成视觉链路回归。

## 参数与算法变化

- `basic_min_piece_edge_mm: 7.0`：允许固定中部四边形的 10 mm 理论短边；现场碎片仍使用
  `min_piece_edge_mm: 20.0`。
- 基础题四块轮廓按固定的 `3/4/4/4` 顶点和模板面积模式全局分配，再进行稳健直线拟合
  与交点细化。
- `target_piece_gap_mm: 0.2`：保持模板刚体形状不变，沿公共接缝法向求最小范数平移。
- 模板匹配成功后，目标中心使用名义模板面积质心加间隙平移；实测轮廓误差只用于质量
  门控，不再偏置目标中心。
- launch 新增 `serial_enabled` 开关；本次常驻 debug 使用 `false`，不启动串口桥或打开硬件
  串口，只运行感知、求解、协调器和网页预览。

## Jetson ARM64 结果

- 基础题照片：A4 检出，场景有效，识别 `4/4` 块，顶点数为 `4/3/4/4`。
- 感知面积：`530.22 / 2477.50 / 1137.44 / 2117.56 mm²`。
- 求解：`SOLVED`，目标外形 `100 mm × 60 mm`，得分 `6.9778`，分差 `1000`。
- 规划中心与理论模板质心加 0.2 mm 间隙位移逐项一致；五条内部公共接缝的法向间隙
  单元测试均为 `0.2 mm`。
- `puzzle_perception_node`：5/5 测试通过。
- `puzzle_solver_node`：8/8 测试通过。
- 测试结束后视觉照片回归进程组已全部停止，没有遗留 ROS 节点。
