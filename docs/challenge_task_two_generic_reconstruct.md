# 发挥题二通用重拼算法

本文记录 Windows 离线迭代出的通用重拼流程。它面向“绿色 A4 上放置 3 或 4 块扑克牌碎片、需要重拼完整牌面”的发挥题二例题；当前验证覆盖黑桃2四矩形样本和 2026-08-01 新增的两张 3 片样本，不代表 Jetson 实机、ROS 实时链路、串口、HMI、单片机或机械放置验收。

## 需求解读

- 输入：单张相机图，包含绿色 A4 区域和 3 或 4 个白色/彩色扑克牌碎片。
- 输出：A4 矫正图、碎片轮廓、重拼候选、歧义分差或候选状态、可视化重拼图和质量门控。
- 约束：不能依赖某一张牌的语义，例如“黑桃2”；可以利用通用扑克牌证据，包括外框白边、内缝图案连续、对角角标和候选分差。

## 候选比较

| 子任务 | 候选算法 | 优点 | 局限/淘汰原因 | 适配度 |
|---|---|---|---|---|
| A4 定位 | 浅绿 HSV 阈值 + 四边形近似 + `warpPerspective` | 比 `minAreaRect` 更贴合新图 A4 边界，减少黑色桌面误入 | 顶边粘连成 5 点时需选最接近 A4 长宽比的凸四边形 | 当前首选 |
| 牌片分割 | 非绿底白卡/打印内容掩膜 + 小核形态学 + `findContours` | 支持白边接近绿底、彩色牌面、全 A4 搜索和 3 片样本 | 仍可能把同一片细小边缘拆开，需要卡片像素比例过滤 | 当前首选 |
| 重拼搜索 | 2x2 全排列 + 每片 0/180 度枚举 | 4 个相似矩形只有 384 个候选，稳定可穷举 | 只适合四矩形牌片 | 已验证分支 |
| 重拼搜索 | 保留源姿态的碎片紧凑候选 | 能处理 3 片和非 2x2 样本，便于调分割和轮廓 | 不是唯一边链解，不能输出控制坐标 | 过渡分支 |
| 重拼搜索 | 通用边链 DP | 能处理 3/4 片不规则碎片，理论上应作为最终通用解 | 尚未在本次实现；下一步接入 | 推荐最终分支 |
| 排序证据 | 内缝墨迹/梯度/亮度连续性 | 不依赖牌面类别，能处理任意花色/点数 | 纯白无纹理缝会给出歧义，必须报告 `AMBIGUOUS` | 主评分 |
| 排序证据 | 外框白边质量 | 约束完整牌边界，避免把内缝放到外侧 | 角标靠近外框，不能把外框要求设成纯白 | 辅助评分 |
| 排序证据 | 对角角标墨迹分布 | 适合扑克牌共性，不关心具体数字/花色 | 有些牌面或裁切可能角标缺失，只作辅助证据 | 辅助评分 |
| 排序证据 | OCR/花色分类 | 可给出语义唯一性 | 训练和部署成本高，且会把例题语义硬编码进主链路 | 暂不采用 |

## 推荐处理顺序

1. 浅绿 HSV 阈值 + 形态学：定位绿色 A4 平面候选。
2. `approxPolyDP` + A4 长宽比四边形选择 + `cv::getPerspectiveTransform`：矫正到 A4 局部平面。
3. 非绿底白卡/打印内容掩膜 + `findContours`：在全 A4 中提取碎片。
4. 面积、外接框、卡片像素比例过滤：剔除绿色背景和桌面边缘误检。
5. 若为四个相似矩形：进入 2x2 全排列和 0/180 度枚举。
6. 若为 3 片或非 2x2：输出源姿态紧凑候选和轮廓诊断，标记边链 DP 待接入。
7. 内缝连续性评分：对候选内缝采样墨迹、Sobel 梯度和亮度 profile，允许小位移对齐后评分。
8. 外框白边评分：检查最终画布四条外边是否保留低饱和、高亮度、低墨迹的牌边。
9. 质量门控：输出 `PASS_RECONSTRUCTED_UNIQUE`、`PASS_RECONSTRUCTED_AMBIGUOUS`、`CANDIDATE_SHAPE_COMPACTED_EDGE_CHAIN_PENDING` 或 `RETRY_DETECTION_OR_LAYOUT_SCORING`。

## 参数与验证

- 四矩形工具绿色 A4 HSV：`H 35..95, S 35..255, V 35..255`，当前用于离线图，不可直接声明为 Jetson 生产阈值。
- 形状工具浅绿 A4 HSV：`H 35..75, S 25..120, V 120..255`，并从 4/5 点近似中选择最接近 A4 长宽比的四边形。
- 白片阈值：`S < 85, V > 75, Lab L > 80`。
- 形状工具碎片掩膜：非绿色 hue、低 Lab b 白卡、彩色/暗色打印内容的并集。
- 四矩形工具牌片数量：固定要求 4 片；否则返回检测失败。
- 形状工具碎片数量：当前允许 2 到 4 片；本次两张新图均保留 3 个主要碎片。
- 唯一性门控：`score_margin >= 0.10` 才认为唯一，否则为 `PASS_RECONSTRUCTED_AMBIGUOUS`。
- 外框门控：`outer_border_score >= 0.72`。
- 内缝门控：`seam_average >= 0.36` 且 `seam_evidence >= 0.05`。

## 主要风险与降级

- 低纹理/纯白区域会导致多个候选近似等价，应输出 `AMBIGUOUS`，不得伪装成唯一解。
- 照片偏暗时固定白色阈值容易漏检，应优先改为相对绿底 Lab 距离或增加曝光一致性。
- 非 2x2 矩形牌片、缺角、遮挡或片数变化时，当前只能输出紧凑候选和轮廓诊断；最终仍应接入轮廓几何 + 边链 DP + 纹理连续性求解。
- Windows 单图回放只能证明离线算法方向，接入 ROS/C++ 前还必须做 Jetson 上的帧率、稳定性、相机曝光和最终重拍验收。
