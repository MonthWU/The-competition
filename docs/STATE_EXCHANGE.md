## 状态包：固定5字节

```text
5B Flagnum 2C BOOL 5D
```

| Flagnum | 含义 | BOOL |
| --- | --- | --- |
| 0x60 | 二维码识别，对应qr功能 | 0x01进入，0x00退出 |
| 0x61 | 物料转盘识别，对应block功能 | 0x01进入，0x00退出 |
| 0x62 | 标靶识别，对应target圆心精定位功能 | 0x01进入，0x00退出 |

0x2C为英文逗号。例如物块进入`5B 61 2C 01 5D`，标靶进入`5B 62 2C 01 5D`，标靶退出`5B 62 2C 00 5D`。

上下位机状态分别记录；每个Flagnum独立进入和退出，允许0x61与0x62同时有效，不用一个状态覆盖另一个。收到状态更新peer_states和诊断事件；0x61进入确认按上述新例外请求一次圆盘测量，其余通知仅记录，均不能切换相机、启动/结束标靶精定位或修改Mission。当前编号表仅定义0x60/0x61/0x62，未知编号、非00/01或错误长度的状态包拒绝；新增编号须同步STATE_FLAGS及接收端约定。

当前本机功能仍按原门控互斥切换：qr进入 → qr退出 → block进入 → block退出 → target进入 → target退出 → block进入。block保留YOLO标靶粗定位用于门控，target为满足原条件后进入的圆心精定位，此次不改自动进入条件。即使分辨率一样，也报告功能变化。编码和状态集合支持后续嵌套功能，并不由收到的状态包强制改变当前流程。

## 发送与关闭顺序

相机线程只记录实际功能变化，不写UART。最多64个模式事件与最新帧在同一锁内原子取出，由主线程按顺序发送；重复进入相同功能不重复排队。队列满时显式失败，不静默丢弃，并预留一个退出事件容量。二维码在设备打开、解码器初始化后通知进入；物块在设备打开及YOLO加载完成后通知进入，重开失败不报告新模式进入；尚在稳定帧等待时不发送测量值。

正常停止及异常清理在相机成功关闭后发送退出，之后关闭UART。关闭超时或写入失败时不保证通知送达；write成功也不等于MCU确认，尚未增加ACK、启动同步握手或重传协议。独立相机预览没有通信主循环，不因此打开UART。

HMI通信快照提供local_states及peer_states（当前有效Flagnum列表），双端状态分别显示，保留进入/退出事件。

## 各类报文

| 类型 | 新报文 | 长度 |
| --- | --- | --- |
| 状态 | `5B Flagnum 2C BOOL 5D` | 5字节 |
| 物块合并 | `5B 71 num (class dx_lo dx_hi dy_lo dy_hi)×num 5D` | 4+5×num字节，num为0～6种 |
| 标靶姿态 | `5B 72 source alpha_lo alpha_hi dx_lo dx_hi dy_lo dy_hi 5D` | 10字节 |
| 二维码 | `5B 70 UTF-8原文 5D` | 变长 |
| 地图与既有命令 | 保持原ASCII方括号格式 | 按原格式 |

原0x54偏差及0x51～0x53绝对标靶坐标兼容编码函数亦替换帧头尾，当前运行不主动发送这些旧测量类型。source=0使用YOLO处理图尺度，source=1使用target模式采集图尺度；详见SERIAL_PROTOCOL.md。

二进制载荷可以包含0x5B/0x5D，例如坐标0x5D5B。MCU按类型确定固定长度；0x71物块合并包则根据num计算4+5×num，不能遇到载荷中的方括号就截断或重新起帧。num按物块种类数计，每种只发送类别码及检测框中心偏差dx/dy，详见SERIAL_PROTOCOL.md。

合法二维码为非空UTF-8原文且一定不含`]`，视觉在解码、任务及编码阶段拒绝含]内容。MCU识别0x70后读取到首个0x5D为止；正文中的`[`允许出现，不能重新起帧。原文、四次发送及flush后的相机交接保持，不需新增转义或长度字段。

原[4]、[24]、[shot]、[skip]及[align_done]/[align_cancel]仍是控制命令，状态包不会进入这些控制分支。
