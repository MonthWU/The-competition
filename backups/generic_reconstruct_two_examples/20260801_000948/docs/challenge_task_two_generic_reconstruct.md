# 发挥题二通用重拼算法

本文记录 Windows 离线迭代出的通用重拼流程。它面向“绿色 A4 上半区放置 4 块矩形扑克牌碎片、下半区需要重拼完整牌面”的发挥题二例题；当前验证只覆盖 `captures/codex_camera_20260731_232232.jpg`，不代表 Jetson 实机、ROS 实时链路、串口、HMI、单片机或机械放置验收。

## 需求解读

- 输入：单张相机图，包含绿色 A4 区域和 4 个白色矩形牌片。
- 输出：2x2 重拼候选、最优布局、歧义分差、可视化重拼图和质量门控。
- 约束：不能依赖某一张牌的语义，例如“黑桃2”；可以利用通用扑克牌证据，包括外框白边、内缝图案连续、对角角标和候选分差。

## 候选比较

| 子任务 | 候选算法 | 优点 | 局限/淘汰原因 | 适配度 |
|---|---|---|---|---|
| A4 定位 | HSV 绿色阈值 + `minAreaRect` + `warpPerspective` | 简单、可解释、当前图稳定 | 强反光或绿色背景大面积粘连时需换成更严格四边检测 | 当前首选 |
| 牌片分割 | HSV/Lab 白片阈值 + 形态学 + `findContours` + `minAreaRect` | 不依赖训练，能适应当前偏暗画面 | 极暗/白片接近绿底时需要动态背景 Lab 距离 | 当前首选 |
| 重拼搜索 | 2x2 全排列 + 每片 0/180 度枚举 | 4 片只有 384 个候选，稳定可穷举 | 不适合未知片数或非矩形碎片，需要回到通用边链 DP | 当前首选 |
| 排序证据 | 内缝墨迹/梯度/亮度连续性 | 不依赖牌面类别，能处理任意花色/点数 | 纯白无纹理缝会给出歧义，必须报告 `AMBIGUOUS` | 主评分 |
| 排序证据 | 外框白边质量 | 约束完整牌边界，避免把内缝放到外侧 | 角标靠近外框，不能把外框要求设成纯白 | 辅助评分 |
| 排序证据 | 对角角标墨迹分布 | 适合扑克牌共性，不关心具体数字/花色 | 有些牌面或裁切可能角标缺失，只作辅助证据 | 辅助评分 |
| 排序证据 | OCR/花色分类 | 可给出语义唯一性 | 训练和部署成本高，且会把例题语义硬编码进主链路 | 暂不采用 |

## 推荐处理顺序

1. HSV 阈值 + 形态学：定位绿色 A4 平面候选。
2. `cv::minAreaRect` + `cv::getPerspectiveTransform`：矫正到 A4 局部平面。
3. HSV/Lab 白片阈值 + `findContours`：提取上半区白色牌片。
4. `cv::minAreaRect`：将每片规整为统一方向的矩形 patch。
5. 全排列枚举：生成 `[top_left, top_right, bottom_left, bottom_right]` 的所有排列和 0/180 度朝向。
6. 内缝连续性评分：对每条内缝采样墨迹、Sobel 梯度和亮度 profile，允许小位移对齐后评分。
7. 外框白边评分：检查最终画布四条外边是否保留低饱和、高亮度、低墨迹的牌边。
8. 对角角标评分：统计四角墨迹分布，优先对角成对但不识别具体字符。
9. 质量门控：输出 `PASS_RECONSTRUCTED_UNIQUE`、`PASS_RECONSTRUCTED_AMBIGUOUS` 或 `RETRY_DETECTION_OR_LAYOUT_SCORING`。

  - `hardcoded_face=false`，未使用“黑桃2”语义。
  - 最优与第二候选分差较小，说明部分低纹理半片物理顺序不强唯一。

## 参数与验证

- 绿色 A4 HSV：`H 35..95, S 35..255, V 35..255`，当前用于离线图，不可直接声明为 Jetson 生产阈值。
- 白片阈值：`S < 85, V > 75, Lab L > 80`。
- 牌片数量：固定要求 4 片；否则返回检测失败。
- 唯一性门控：`score_margin >= 0.10` 才认为唯一，否则为 `PASS_RECONSTRUCTED_AMBIGUOUS`。
- 外框门控：`outer_border_score >= 0.72`。
- 内缝门控：`seam_average >= 0.36` 且 `seam_evidence >= 0.05`。

## 主要风险与降级

- 低纹理/纯白区域会导致多个候选近似等价，应输出 `AMBIGUOUS`，不得伪装成唯一解。
- 照片偏暗时固定白色阈值容易漏检，应优先改为相对绿底 Lab 距离或增加曝光一致性。
- 非 2x2 矩形牌片、缺角、遮挡或片数变化时，本工具不适用，应回到轮廓几何 + 边链 DP + 纹理连续性求解。
- Windows 单图回放只能证明离线算法方向，接入 ROS/C++ 前还必须做 Jetson 上的帧率、稳定性、相机曝光和最终重拍验收。
