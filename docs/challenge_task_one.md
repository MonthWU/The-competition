# 发挥题一视觉与串口流程

本文按 `slove.md` 的通用平面刚性拼图方法，重构现场纯白工况的算法思路。发挥题一仍是 26E 视觉项目中的任务 2：视觉侧只负责感知、求解、放置后复核和结构化输出，不把机械抓取、路径规划或串口传输本身混入拼图算法。

## 1. 已确认需求

- 任务命令为 `[task,2]`。
- 拼图区域是纵向 A4 纸；沿长边中线划分上、下区域，全部初始碎片轮廓必须完整位于上半区。
- 先识别绿色 A4/绿色矩形框并记录其相对相机中心的像素坐标；绿框中心只用于场景记录和调试，不约束最终拼图中心。
- 白色拼图块数量为 1--4，每片最多 5 条边，每条边至少 20 mm。
- 每片在完成矩形中至少有一条完整边位于目标矩形外边界。
- 目标矩形长边范围为 90--120 mm，短边范围为 50--90 mm。
- 最终矩形方向自由，中心可在下半区安全边界内选择；完整目标轮廓必须位于下半区。
- 首次有效求解后缓存本轮全部 `[x0,y0,x1,y1,angle]`；单片机完成当前片后返回
  `[move,ok]`，Jetson 才发送队列中的下一片。
- 题面 `20 mm` 是最终视觉验收上限；算法内部可配置更严格门限，但不得把更宽松门限写成题面允许值。

## 2. 重构后的核心认识

发挥题一不能把一次 `approxPolyDP` 得到的多边形当成真实碎片几何。真实场景中，镀锌薄铁片、白纸贴面、反光、阴影、形态学开闭运算和 A4 平面映射都会让观测轮廓产生偏移。正确策略不是任意允许重叠，也不是独立缩放碎片，而是显式区分三种几何：

1. **原始轮廓**：`findContours(RETR_EXTERNAL, CHAIN_APPROX_NONE)` 得到的有序毫米轮廓，保留测量细节，用于复核、残差和 SDF/栅格评分。
2. **名义多边形**：由多 epsilon `approxPolyDP` 初始化，再对边段做稳健直线拟合和交点求得，用于候选生成、边匹配和刚体位姿搜索。
3. **不确定带**：由标定误差、分割误差、直线拟合残差和重复拍摄波动估计，分成核心区、名义区和外包区，用于判断重叠、缺口和边长不一致是否可解释。

求解器只允许二维刚体平移和旋转。默认禁止每块碎片独立缩放、拉伸、剪切、镜像或弯曲；如果出现“名义几何轻微重叠但实物可拼”的情况，只能通过已记录的不确定度、全局尺度误差或边法向小幅偏置解释，并写入诊断明细。

发挥题一的轮廓顶点必须对应实际物理边界。不得为了把候选压到 3--5 边、满足最小边长或提高求解成功率，自动删除大钝角顶点、合并两条真实边或用凸包/外接矩形替代原轮廓。若分割、`approxPolyDP` 或直线拟合得到的边数、边长、残差不可信，应返回 `RETRY` 或 `FAIL`，重新采图或调分割参数，而不是修改碎片形状。

## 3. 推荐主链路

```text
[task,2]
  -> 直接触发当前任务扫描
  -> 固定相机取稳定清晰帧，拒绝遮挡、失焦和曝光异常帧
  -> green_a4_* HSV 掩膜检测绿色 A4/绿框
  -> A4 平面映射到毫米坐标，映射无效则拒绝物理坐标输出
  -> 在 A4 校正图内动态采样绿色纸面 Lab 背景
  -> 反选白色/浅色碎片前景，排除边界线、A4 边缘和电磁铁颜色
  -> connectedComponentsWithStats 粗筛候选数量、面积和区域
  -> findContours(RETR_EXTERNAL, CHAIN_APPROX_NONE) 提取完整外轮廓
  -> 多 epsilon approxPolyDP 生成 3--5 边初始分段
  -> 按初始分段对完整轮廓点做稳健直线拟合和交点细化
  -> 生成 raw_contour_mm、nominal_polygon、fitted_edges 和 uncertainty_band
  -> 初始碎片完整位于上半区、1--4 片、最小边长 20 mm 门控
  -> 基于长度区间、方向相反、端点覆盖和核心区不重叠生成公共边候选
  -> 枚举外边界候选，要求目标矩形尺寸、外边贡献和直角关系合法
  -> 小规模子集 DP / 二叉合并 / 最少候选优先回溯生成完整布局
  -> 对离散拓扑做刚体位姿求精和分层重叠、缺口、矩形评分
  -> 保留最佳和次优候选，执行 PASS/RETRY/FAIL 质量门控
  -> 在下半区可行区域内选择自由目标中心和方向
  -> 缓存整套 PuzzlePlacement 队列
  -> 发布当前队首并等待 [move,ok]
  -> 收到确认后直接发送队列中的下一条
  -> 全部确认后 COMPLETE -> IDLE/NO_TASK
```

`WAIT_TOOL_CLEAR` 不属于当前任务 2 的默认生命周期。现场 `[move,ok]` 到达时机械结构
可能尚未离开 A4 视野，因此拼装阶段不在每片确认后重新扫描；若需要最终复核，应作为
单独的机械退让后步骤，而不是恢复旧的 `puzzle/tool_clear` 话题依赖。

## 4. 候选方案比较

| 子任务 | 候选方案 | 优点 | 局限/淘汰原因 | 推荐结论 |
|---|---|---|---|---|
| 前景分割 | A4 内动态 Lab 背景反选 | 可解释、无需训练、适合绿色 A4 与白色碎片 | 需要真实光照样本调阈值，反光会降低轮廓置信度 | 主链路 |
| 前景分割 | 白色 HSV 固定阈值 | 实现简单 | 对阴影、曝光和自备碎片颜色不稳 | 仅作显式关闭背景反选后的回退 |
| 前景分割 | YOLO-seg / U-Net | 可处理复杂背景 | 需要掩膜标注和 Jetson 实测，边界仍需几何后处理 | 真实样本证明经典分割不足后再比较 |
| 轮廓建模 | 单次 `approxPolyDP` | 快速 | 对阈值和锯齿敏感，无误差模型 | 只作边段初值 |
| 轮廓建模 | 完整轮廓 + 直线拟合 + 不确定带 | 可解释，可输出残差和拒绝原因 | 实现复杂度更高 | 发挥题一推荐目标 |
| 组合搜索 | 精确等边回溯 | 理想数据快 | 真实测量中容易误拒 | 只作理想测试基线 |
| 组合搜索 | 容差边匹配 + 子集 DP / 回溯 | 适合 1--4 片，剪枝明确 | 依赖误差统计和质量门控 | 主链路 |
| 位姿求精 | 连续角度暴力搜索 | 概念直观 | 搜索空间大，速度和精度难兼顾 | 不作为默认方案 |
| 位姿求精 | 离散拓扑后鲁棒小规模优化 | 可输出残差和修正量 | 依赖合理初始拓扑 | 后续重构方向 |

## 5. 建议数据结构

现有 `PieceModel` 只保存 `polygon_local_mm`、中心、拾取点、角度和面积，足以支撑当前子集 DP，但不足以解释真实轮廓偏差。下一步建议把求解输入扩展为概念上的 `PieceGeometry`：

```text
PieceGeometry
├─ piece_id
├─ raw_contour_mm
├─ nominal_polygon
├─ fitted_edges
├─ edge_uncertainties
├─ vertex_covariances
├─ core_region
├─ nominal_region
├─ outer_region
├─ observation_pose
└─ quality_metrics
```

每条 `FittedEdge` 至少保留起止顶点、拟合直线、长度、角度、法向误差、角度误差、拟合残差、内点比例和置信度。`PuzzleResult` 不应只给目标位姿，还应给 `status`、邻接图、最佳/次优分数、评分分解、所需修正量、位姿不确定度和失败原因。

为兼容现有 ROS2 消息，可以先在求解器内部扩展结构，再把关键诊断压缩到 `PuzzlePlan.status` 和日志；等消息契约需要长期稳定后，再扩展接口字段。

## 6. 边匹配和矩形评分

公共边候选至少检查：

- 长度区间相容，而不是严格相等；
- 两条边拼接后方向相反；
- 端点或重叠区间可在不确定度内对齐；
- 两个碎片位于公共边两侧；
- 核心区没有确定性重叠；
- 名义重叠、外包区相交和缺口进入软评分，而不是单独决定成败。

矩形评分至少检查：

- 所有有效碎片只使用一次；
- 完成矩形长短边处于 90--120 mm 和 50--90 mm 范围；
- 外边方向形成两组近似正交主方向；
- `cv::fillPoly` 或 SDF 复核的并集填充率、空洞面积和重叠面积合格；
- 每块至少一条完整边贡献目标矩形外边；
- 目标整体位姿经过自由旋转和平移后完整落在 A4 下半区安全边界内。

轻微名义重叠只在方向、深度和对应边不确定度一致时可作为软惩罚接受；核心区重叠超过验收值必须拒绝。只有依赖过大修正、最佳/次优接近、轮廓质量不足或映射不稳定时，返回 `RETRY`，不得发送猜测坐标。

## 7. 下半区目标位姿

每次有效场景求解后仍存在下半区内的整体平移和整体旋转自由度。求解器按以下规则选出唯一可执行位姿：

1. 以 `y=148.5 mm` 为下半区起点，配置目标边界原点、宽度、高度和安全边距。
2. 对候选整体旋转和整体平移进行求解，要求每片目标多边形的所有顶点都在下半区安全边界内。
3. 首次有效扫描时全部碎片必须完整位于上半区；后续闭环扫描允许已放置碎片位于下半区，并把它们作为当前场景的一部分重新求解。
4. 以总移动距离、总旋转量、几何误差和修正量联合评分。全等碎片交换位置形成的等价解允许按移动成本确定性选择；只要尺寸、外边、重叠、孔洞等硬约束全部通过即可执行。

目标矩形不强制长边水平，因此 `angle` 始终来自求解器完整刚体变换，而不是绿框方向或 `minAreaRect` 的固定角度。

## 8. 串口确认与闭环复核

- 同一时刻只允许一个五字段帧等待确认。
- `serial_bridge_node` 仅在五字段帧已完整写入 UART 后进入等待确认状态。
- `[move,ok]` 不携带 `piece_id`，串口桥利用“单一未完成请求”映射为对应的 `puzzle/placement_done`。
- 提前、重复或无待执行请求时收到的 `[move,ok]` 必须忽略，并记录 `BUG_POINT:MOVE_ACK_STATE`。
- 任务 2 参考当前批量队列结构：首次求解缓存整套移动计划，确认当前片完成后只下发
  队列中的下一片。
- 首次求解仍必须使用现场纯白未知碎片的通用几何流程，不得回退到基础题固定模板。
- 前景框选与基础题共用绿色 A4 背景反选入口；`white_piece_*` HSV 只作为显式关闭 `plain_piece_use_a4_background_inversion` 后的回退路径。

放置后视觉闭环至少要重新采图、恢复 A4 毫米坐标、定位新放置碎片、将实测轮廓与计划轮廓配准，并估计平移和旋转误差。若误差可通过小幅内部修正继续，应更新当前场景后再求解下一片；若出现明显错放、遮挡或轮廓缺失，应返回 `RETRY` 或 `FAIL`。

## 9. 坐标与角度

- `x0,y0`：当前拼图块中心，相机中心为 `(0,0)`，默认 X 向右、Y 向下，单位像素。
- `x1,y1`：当前求解结果中该拼图块的目标中心，使用同一坐标系。
- `angle`：从当前姿态到目标姿态的完整刚体旋转差；顶视图逆时针为正、顺时针为负，范围 `[-180,180)`。
- 20 mm 边长、目标矩形尺寸、重叠、缺口和顶点距离必须在平面校正后的毫米坐标中判断，不能由未校正原图像素直接估算。
- 未通过实测验证的工作区绝对映射不得向控制侧输出绝对坐标。

## 10. 主要质量门控

- 绿色 A4/绿框未检测：`GREEN_A4_NOT_FOUND`。
- A4 平面映射无效：`CALIBRATION_REQUIRED` 或 `WORKSPACE_MAPPING_INVALID`。
- 任一初始碎片轮廓不完整位于上半区：`INITIAL_PIECE_OUTSIDE_UPPER_REGION`。
- 有效拼图块数量不在 1--4：`PIECE_COUNT_INVALID`。
- 任一检测多边形边数超过 5 或边长不足 20 mm：该候选不进入场景；若导致数量不可信则拒绝求解。
- 轮廓截断、孔洞异常、直线拟合残差过大或跨帧不稳定：`RETRY`。
- 无满足 90--120 mm × 50--90 mm 的矩形：`NO_VALID_RECTANGLE` 或 `NO_FEASIBLE_PLACEMENT`。
- 任一拼图块没有完整外边落在矩形边界：候选布局拒绝。
- 核心区发生不可解释重叠、目标空洞过大或修正量超过不确定度：`FAIL` 或 `LOW_QUALITY_LAYOUT`。
- 最佳和次优候选几何意义不同且分数接近：`RETRY`；全等片交换或整体自由位姿造成的等价解可按移动成本确定性选择。
- 五字段帧或坐标非有限值：不进入串口发送队列。
- 等待 `[move,ok]` 超时：`PLACEMENT_TIMEOUT`。
- 任务 2 计划超时独立配置为 30 s；基础题仍使用 5 s，避免 4 片约束搜索被提前中止。

## 11. 分阶段落地建议

1. **文档与接口阶段**：把当前 `PuzzleSolverCore` 的输入从单一多边形思维扩展为 `PieceGeometry` 思维，但先保持现有 ROS2 消息兼容。
2. **感知阶段**：在 `puzzle_perception_node` 中输出完整轮廓、边拟合残差、边长 P50/P95 或多阈值稳定性诊断；拒绝排序截断造成的噪声候选。
3. **求解阶段**：在当前子集 DP 基础上加入边长区间、核心区重叠、名义区软惩罚、目标空洞和第二名候选差异诊断。
4. **执行阶段**：首次求解缓存整套移动队列；每次 `[move,ok]` 后直接发送下一条。
   若需要落位误差复核，应等机械结构退出 A4 视野后作为单独复核步骤执行。
5. **验收阶段**：用真实白色薄铁片、现场 A4、正常室内光照和 Jetson ARM64 记录顶点误差、布局正确率、端到端耗时和最终 20 mm 顶点验收结果。

## 12. 验证边界

代码单元测试只能证明几何约束、完整目标轮廓留在下半区和确认状态机的确定性行为。Windows 静态检查只能证明文档或源码一致性。真实白色拼图、现场光照、绿框定位误差、顶点毫米误差、完整布局正确率、UART 端到端行为、机械落位误差和 2 min 整机时限仍必须在目标 Jetson 与真实机构上测量，未取得数据前不得宣称精度或成功率已达标。
