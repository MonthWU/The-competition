## 场地修改接口

仅有雷达版需要修改`projects/with_radar/config/route.json`，重启后生效；运行过程中不热加载地图，避免半份配置混入同一任务。无雷达版没有此配置文件。

| 字段 | 意义与填写规则 |
| --- | --- |
| confirmed | 地图和任务已核对后设true；默认false，不能通过改标志跳过实际填写 |
| frame | 场地坐标系名称；定位快照必须完全相同 |
| vehicle_radius_m | 覆盖当前完整车体及机构的外接圆半径，米；默认null |
| margin_m | 额外安全余量，米，非负；默认null |
| nodes | 任意非空字符串节点名到[x米,y米]的字典；名字不能以@开头 |
| edges | 无向道路列表，每项为`{"nodes":["节点名1","节点名2"],"clearance_m":实测净空半径}` |
| start_node | 起点节点名；默认null |
| goals | 必须依次经过的节点名列表；需要返回时在末尾加入原起点 |
| fixed_obstacles | `[x米,y米,半径米]`列表；未知保持null，明确没有障碍才能填[] |

所有节点和障碍使用同一坐标系与米单位。道路边表示事先确认允许通行的直线中心线，不能穿过禁止区域；clearance_m是整条边到道路禁行边界的最小距离。规划器只沿所配置道路搜索，不能自行从5×5格号、仿真出生点或二维码板预设推导真实地图。按固定及观测障碍、车体外接圆和余量进行线段碰撞检查，切触也视为阻断。道路净空不足会被排除；任何一段任务不可达时返回no_path，不输出前半段冒充完整路径。

纯算法示例保存在`tests/test_navigation.py::sample_map`和`artifacts/todo1_plan_examples.json`；均明确为人工数据，不会自动导入实机配置。库内的一次规划分支保留作纯算法测试，不由无雷达应用使用。

## 有雷达版定位接口

在`projects/with_radar/config/board.json`设置`radar.device`及伸出锁定后的真实`extrinsic=[x米,y米,yaw度]`，完成标定后将extrinsic_calibrated设true。不得将仿真安装值当作实测值。

`navigation.pose_file`默认为null；填写相对于本版config目录的路径或绝对路径。定位生产者需原子替换该JSON文件，避免读到半写入内容。接口格式如下，字段后的解释用于文档，实际JSON不包含注释：

| 字段 | 意义 |
| --- | --- |
| valid | 布尔true表示定位生产者已确认；false或缺失时不规划 |
| frame | 与route.json的frame一致 |
| x_m / y_m | 车体参考原点在场地坐标系中的位置，有限米数 |
| yaw_deg | 车体+x轴相对地图+x轴逆时针角，有限度数 |
| timestamp_unix | 对应采样的Unix秒时间戳，生产者与本机时钟需同步 |

当前未将Gazebo/Cartographer仿真真值接入实机，也未提供完整实机定位器。后续可由定位模块写快照，不需要修改规划核心。此文件不是下位机运动接口。

默认定位过期门限0.5秒，雷达使用自身stream_timeout_s；定位与扫描采集时间相差不超过0.1秒。读取定位快照最多10Hz，规划最多2Hz，均可配置；姿态与地图坐标系不匹配、未来时间、外参未确认或传感器缺失时撤下路线，不复用旧路线。雷达采集时间仍是主机read时刻，不是经过硬件同步证明的曝光/扫描测量时间；默认同步容差需实测调整。

动态规划使用C1顺时针角的原始有效采样，经安装外参、定位航向和平移转换为地图点。没有只挑选黑色圆柱，所有有效回波都可阻断路线。观测按0.05米格聚合，以格心及半对角线覆盖格内点，另加0.03米观测余量，再加车体包络；参数可修改。最多保留4096格，超过后撤下路线并锁定observation_limit，不驱逐旧障碍以开放未知道路。

已观测障碍在本次任务内保留，下一圈缺少回波不代表盲区清空。该实现支持遇到新障碍绕行，尚未实现移动障碍消失后的自动解封。自体轮子回波尚未按实测外参过滤，可能保守地阻断道路；不得为得到路线而盲目删除回波。实车验收前需补充经标定的自体过滤及遮挡检查。

行驶中位置在snap_m（默认0.05米）范围内投影接入最近配置道路，连接段仍检查净空及障碍；远离道路则off_route。接近下一个任务点的goal_tolerance_m默认0.05米，每个有效规划周期最多推进一个任务点。这里的到达只表示几何位置条件，不代表扫码、抓取或机构任务完成。尚未实施速度、转弯半径、车体朝向约束或控制闭环。
